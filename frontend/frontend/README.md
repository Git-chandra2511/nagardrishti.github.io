# Nagar Drishti — Premium Light UI

This version keeps the existing Nagar Drishti demo functionality but gives the frontend a cleaner, editorial, premium light interface inspired by the visual language of the reference design: spacious layouts, large typography, white surfaces, thin borders, soft shadows, restrained color, and rounded cards.

## Run

```bash
npm install
npm run dev
```

The Vite app uses the existing project structure and localStorage demo flow. Firebase-ready files are preserved.

## Important

The redesign is implemented as Nagar Drishti's own UI system rather than copying any specific website from the reference gallery.
